# 🤖 AI CLI Assistant

A modular, real-time streaming AI CLI Assistant built in Python. Designed as a practical foundation for AI Engineering.

---

## ⚡ Features

- 🐍 **Pure Python Architecture**: Clean modular design separating UI, configuration, LLM clients, and memory storage.
- ⚡ **Real-time Streaming**: Tokens stream directly to your terminal as they are generated by the model.
- 🧠 **Context & Session Memory**: In-memory message context and automatic JSON session file persistence (`.chat_history.json`).
- 🤖 **Multi-Provider Support**: Seamless support for Google Gemini (`gemini-2.5-flash`) and OpenAI (`gpt-4o-mini`).
- 🎨 **Rich Terminal UI**: Beautiful banners, styled prompts, colored logs, and Markdown output.
- ⚡ **Slash Commands**:
  - `/help`: Show available slash commands
  - `/clear`: Clear active conversation history
  - `/history`: View session message history
  - `/system <prompt>`: View or change system instructions
  - `/model`: View active provider and model
  - `/exit` or `/quit`: Save session and exit

## 🚀 Quick Start Guide

### 1. Setup Virtual Environment & Dependencies

```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Install requirements
pip install -r requirements.txt
```

### 2. Configure API Key

Copy `.env.example` to `.env`:

```bash
copy .env.example .env
```

Open `.env` in your editor and add your **Google Gemini API Key** (or OpenAI API key):

```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### 3. Launch the AI CLI Assistant

```bash
python main.py
```
